# לימוד אוטומציות 🤖

תיקייה ללימוד בנייה של אוטומציות **מאפס**, דרך פרויקט תרגול אמיתי:

> עולה פרק פודקאסט חדש → המערכת מתמללת אותו → AI מסכם → הכל מגיע אליי למייל.

**המטרה האמיתית:** לשמוע פודקאסט וגם להחזיק את הטקסט מולי — כדי להבין טוב יותר תוך כדי, ולחזור על זה אחר כך.
