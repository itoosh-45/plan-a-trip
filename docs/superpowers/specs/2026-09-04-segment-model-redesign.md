# אפיון — מעבר למודל מבוסס מקטעים

תאריך: 2026-09-04 · מחליף את החלקים הרלוונטיים באפיון מ-2026-09-03.

## מה השתנה בקצרה

התאריך חדל להיות מפתח השיוך. לכל טיול יש טווח תאריכים משלו, ומתוכו נגזרים
יעדים (מקטעים) עם טווחי תאריכים. הוצאה, תקציב ופריט צ׳קליסט משויכים למקטע ולא
לתאריך. פיצ׳ר סטטוס הטיול נמחק לחלוטין.

## מודל הנתונים

| טבלה | שדות שנוספו או השתנו |
|---|---|
| `trips` | `startDate`, `endDate` · `currency` (במקום `homeCurrency`) · `totalBudget` = תקרה · **בלי** `status` |
| `segments` | `kind: 'general' \| 'place'` · `allocation` · למקטע `general` אין תאריכים |
| `expenses` | `segmentId` (חובה) · `kind: 'expense' \| 'withdraw' \| 'cashSpend'` · `date` נשמר אוטומטית ואינו נשאל |
| `items` | סכום מתוכנן בלבד. **בלי** `actualAmount` ו-`payStatus` |
| `prepTasks` | `stage: 'before' \| 'during' \| 'after'` · `urgency: 'critical' \| 'important' \| 'normal'` · `segmentId` אופציונלי |
| `categories` | `icon` |
| `wallets`, `walletTx` | אינן בשימוש. נשארות בסכימה כדי שגיבויים ישנים ייובאו |
| `budgets` | אינה בשימוש. התקציב עבר לשדה `allocation` שעל המקטע |

`DB_VERSION = 2`. אינדקסים חדשים: `expenses.segmentId`, `prepTasks.stage`.

## חוקים שאסור לשבור

1. **שער נצרב ברגע ההזנה.** עדכון שער לא נוגע ברשומה קיימת.
2. **רשומה שכבר במטבע הטיול מוצגת כמו שהיא.** רק מטבע אחר עובר המרה, ותמיד
   דרך השקל. זו הנקודה היחידה שבה מתבצעת המרה (`money.tripTotals`).
3. **הכסף במקום אחד.** `expenses` היא הטבלה היחידה שסופרים ממנה כסף שיצא.
   פריט מסלול נושא עלות מתוכננת בלבד.
4. **נוסחת המזומן.** `סך הוצאות = הוצאות שאינן מזומן + סך המשיכות`, ובפילוח
   הקטגוריות `סך המשיכות = הוצאות המזומן בפועל + "מזומן בארנק"`. שני החישובים
   יושבים באותה פונקציה כדי שלא יוכלו להיפרד.
5. **מקטעים לא חופפים** ונמצאים בתוך טווח הטיול. ולידציה ב-`saveSegment`.
   המקטע `general` מוחרג משתי הבדיקות.
6. **חריגת תקציב מסומנת ולעולם לא חוסמת שמירה.**

## מיגרציה (`js/migrate.js`)

רצה ב-boot ואחרי שחזור גיבוי, חסומה מאחורי `settings.schemaVersion`.
כל רשומה שנוצרת בה נושאת מזהה דטרמיניסטי (`wtx-<id>`, `item-<id>`), ולכן
הרצה חוזרת דורסת את עצמה במקום לשכפל. **שום טיול, הוצאה או פריט לא נמחק.**

מיפוי הצ׳קליסט: `לפני`/`בדרך` → `before` · `בשהות` → `during` · `בחזרה` → `after`.
דחיפות לפי העדיפות הקיימת: `חובה` → קריטי · `רלוונטי` → חשוב · `נוחות` → רגיל.

## מסכים

ניווט תחתון בן 4: רשימת הכנה · תכנון · הוצאות · סיכום. הגדרות הן אייקון בהדר.

- **רשימת הכנה** — עמוד מלא, שלוש קטגוריות מתקפלות, בכל אחת שלושה אזורי דחיפות.
  גרירה משנה דחיפות בלבד; מעבר בין קטגוריות דרך "העבר ל…".
- **תכנון** — תקרת תקציב והקצאות, ניהול יעדים, וכניסה ליעד לתצוגת ימים.
- **הוצאות** — ארנק מזומן בראש, קיבוץ לפי יעד עם סיכום ביניים, פירוט גלוי תמיד.
- **סיכום** — כל יעד מול ההקצאה שלו, ופילוח קטגוריות לפי כלל המזומן.
