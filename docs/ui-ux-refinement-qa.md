# QA לסבב חידוד UI/UX

תאריך: 2026-09-29 · branch: `codex/ui-ux-refinement`

## בוצע בקוד

- טיפוגרפיה וריווח לרשימות, שדות וניווט; צבעי הבסיס נשמרו.
- מסך פתיחה יחיד, יצירת טיול ושחזור מגיבוי; משתמש עם טיול קיים אינו מקבל פתיחה אוטומטית.
- הסבר מקומי לכל שלב ושדה באשף; שלבי הרשות ניתנים לדילוג.
- טעינת שער חסר בכניסה לתקציב; הודעה לפני שמירה אם אין שער; כל ההמרות נבדקות לפני כתיבה.
- ״כללי״ מקובץ בתצוגה תחת יעד מקום יחיד בתכנון, בהוצאות, בסיכום ובמשימות. אין שינוי ב־`segmentId`, ב־IndexedDB או בשערים היסטוריים.
- סמל הנייר בטאב הגדרות; cache version חדש ומודול תצוגת היעדים נוסף ל־offline shell.

## בדיקות שעברו מקומית

- `node --check` לכל קובצי JavaScript שהשתנו ולבדיקת התצוגה החדשה.
- טעינת גרף המודולים של מסכי הפתיחה, התכנון, ההוצאות והסיכום ב־Node.
- נתיבי imports מקומיים וכל 41 משאבי ה־Service Worker קיימים.
- בדיקות חישוב תצוגה ל־0, 1 ו־2 יעדים, הוספה והסרה, שמירת מזהה וסכומי ״כללי״.
- בדיקת המרה ₪ → מטבע זר ומצב שער חסר ברמת פונקציית ההמרה.
- `git diff --check`.
