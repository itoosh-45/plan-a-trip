# הפעלת המפות וגרסת הבדיקה

## מצב המימוש

הקוד נמצא בענף `codex/offline-map-packing-updates`. אין שינוי ב־main או בפריסה הפעילה. הפיתוח בוצע בצ׳אט הנוכחי לפי התוכנית שאושרה.

התצוגה משתמשת ב־MapLibre GL JS 5.20.0 וב־PMTiles JS 4.3.0 המוטמעים ב־vendor, עם הודעות הרישוי. נתוני הרחובות הם Protomaps/OpenStreetMap בבניית 2026-10-03. החבילות הן חילוצים מלבניים ויכולות לכלול גם חלקים ממדינות שכנות; שמות האזורים בממשק מתייחסים לתכולה העיקרית. הם אינם גבולות מדיניים מדויקים. שמונה חבילות הרחובות הראשונות כוללות רמות פירוט 0–15. חבילות סקירת המדינה בקטלוג העולמי מוגבלות לרמת הפירוט המוצהרת בכל רשומה; זום נוסף מגדיל את אותו פירוט.

## אחסון וייצור חבילות

הארכיונים המלאים נמצאים ב־`scratch/map-tools/`; מקטעי ההורדה ב־`map-packages/`. שתי התיקיות מוחרגות מ־Git. קובץ `data/map-packages.json` כולל גודל מדויק ו־SHA-256 לכל מקטע. אין מידע משתמש באף אחת מהתיקיות: טיולים, נקודות ומידע אישי נשארים בדפדפן בלבד.

הפקת הקטלוג:

```powershell
python scripts/maps/build-catalog.py
```

הסקריפט דורש את הארכיונים האמיתיים ומריץ `pmtiles verify` לפני חלוקה למקטעים של עד 4 MiB. במקרה שחבילה חסרה או אינה תקינה הוא נכשל. כדי להוסיף חבילה, יש לחלץ ארכיון לפי גבולות, להוסיף הגדרה ב־DEFINITIONS, להפיק את הקטלוג ולפרסם את המקטעים יחד איתו.

## תצוגה מקדימה נפרדת

### שכבות לוויין ותבליט

בורר סוג המפה כולל רחובות, לוויין, לוויין עם שמות ותבליט. הרחובות נשארים מבוססי Protomaps/OSM עם תמיכה מלאה בחבילות שהורדו. השכבות הנוספות נטענות ישירות דרך HTTPS מ־EOX::Maps, ללא מפתח API וללא העברת נקודות הטיול לשרת המפות; כמו בכל שירות אריחים, הבקשות חושפות לספק את אזור התצוגה וכתובת הרשת. תצלומי Sentinel-2 משנת 2024 הם ברזולוציה של כ־10 מטר. המקור אינו שירות תצלומי אוויר ברזולוציית מבנים.

שירות הלוויין מיועד כאן לשימוש אישי ולא מסחרי לפי CC BY-NC-SA 4.0, עם ייחוס בתוך המפה: https://cloudless.eox.at/documentation/license . שירות תבליט כולל ייחוס לנתוני OSM וליתר המקורות ולרינדור EOX: https://maps.eox.at/ . השרתים הציבוריים כפופים להגבלת קצב ולזמינותם. לפני שימוש מסחרי יש להתאים את רישיון הלוויין או לבחור ספק אחר.

כעת קיימות חבילות לוויין נפרדות. הסקריפט `scripts/maps/build-satellite.py` יוצר ארכיוני JPEG PMTiles עם המקור והרישיון המקוריים, מאמת אותם, ומחלק למקטעים עם SHA-256. נתוני השרת הם לשימוש אישי/לא מסחרי תחת רישיון המקור, ואינם ממותגים תחת רישיון חדש. הורדה לטלפון משתמשת באותו מנגנון המקטעים של הרחובות וב־IndexedDB הנפרד. גיבוי משתמש אינו כולל את נתוני הלוויין. חבילת לוויין אינה מחליפה חבילת רחובות: לשמות מקומות אופליין מעל הלוויין צריך להוריד גם רחובות באזור.

כאשר האזור בתצוגה מכוסה בחבילות לוויין שהורדו, הרינדור קורא מהן ולא פונה לשירות האריחים המקורי. מחוץ לכיסוי, אונליין יכול להציג EOX ומודיע שהאזור לא הורד; אופליין מציג הודעת אזור חסר. הגדלה מעבר לפירוט שהורד מציגה הודעת פירוט. ללא חבילת לוויין מוכנה, צפיית לוויין אונליין משתמשת ב־EOX, ומעבר לאופליין חוזר לרחובות. תבליט עדיין דורש רשת. מטמון HTTP רגיל אינו נחשב חבילת אופליין שלמה.

### קטלוג מדינות עולמי והכנה לפי בקשה

`data/world-map-packages.json` מבוסס על Natural Earth, נתונים ברשות הציבור: https://github.com/nvkelso/natural-earth-vector . יחד עם המדינות הראשונות, החיפוש כולל 258 מדינות וטריטוריות. לכל אחת חבילת סקירת רחובות ואפשרות לוויין לפי המקור; אנטארקטיקה אינה מוצגת עם חבילת Sentinel-2. החיפוש תומך בשמות עבריים/אנגליים, קוד מדינה, אזור/עיר קיימים וסינון סוג. אין כאן קטלוג מלא של כל עיר וכל אזור בעולם.

`scripts/maps/build-world-catalog.py` מפיק את האינדקס מתוך `scratch/map-tools/world-countries.geojson`, שהורד ממאגר Natural Earth הרשמי. הכנת חבילה חדשה מופעלת באמצעות `map_package_service.py` ונתיבי `/api/prepare-map-package`, `/api/map-package` ו־`/api/map-packages` בשרת הבדיקה. החבילה מוכנה בשרת תחילה, ואז גודלה האמיתי מוצג; המשתמש לוחץ ״הורד״ בנפרד. גודל משוער אינו מוצג כגודל מדויק. רשומות מוכנות נבדקות ב־PMTiles ונשמרות לצד הקבצים, והלקוח מאמת כל מקטע לפני סימון ״מוכן לאופליין״.

השרת מקבל רק מזהי קטלוג מאושרים, ולא כתובות, גבולות או נתיבי קבצים מהמשתמש. מקור הרחובות נעול לבניית Protomaps; מקור הלוויין נעול ל־EOX 2024. רצה הכנה אחת בכל פעם, עד שלוש בקשות ממתינות, עם בדיקת מקום בשרת. הורדת מקור הלוויין מוגבלת לשתי בקשות לשנייה לתהליך, עם המתנה והשהיה חוזרת במגבלת קצב. רמות פירוט סקירה מותאמות לגודל המדינה כדי להגביל מספר אריחים; אינן תמונות מפורטות של מלונות. הקטלוג והקבצים ציבוריים; שום מידע טיול אינו נשלח לשרת ההכנה.

לפני פריסה קבועה חייבים לארח את שרת ההכנה ואת הקבצים באירוח קבוע או להכין מראש את החבילות המבוקשות. Cloudflare Worker אינו מריץ את כלי PMTiles. המודול תומך בהפניה לשרת HTTPS מהימן דרך `MAP_PACKAGE_SERVICE` ומחזיר הודעת אי־זמינות אם לא הוגדר. שרת הבדיקה הזמני והמנהרה אינם תשתית ייצור. main נשאר ללא שינוי עד בדיקת המשתמש וסגירת דרישות האירוח.

גרסת הבדיקה מוגשת באמצעות `preview-server.py` בפורט 8125, עם קישור HTTPS זמני של Cloudflare Tunnel. זהו פתרון לבדיקת המשתמש לפני main, ולא פריסה קבועה. כתובת הבדיקה תלויה בהמשך ריצת השרת והמחשב. אם מנהרה מופסקת, פתיחה מחדש עשויה להפיק כתובת אחרת.

```powershell
python scripts/build-preview.py
python preview-server.py 8125 scratch/preview-dist
& scratch/map-tools/cloudflared.exe tunnel --url http://127.0.0.1:8125 --no-autoupdate
```

סקריפט בניית התצוגה מעתיק רק נכסי אפליקציה ומפה, ומפיק מזהה מטמון מתוך תוכן הקבצים. יש להריץ אותו בכל שינוי לגרסת הבדיקה, כדי שעדכון יצביע על מעטפת חדשה ולא יחליף חלקים בתוך מטמון פעיל. המקטעים נוצרים כקישורים קשיחים כשהמערכת תומכת בכך כדי למנוע עותק נוסף של כמה GB. הקובץ המעודכן מופיע באותה כתובת בדיקה.

השרת מאפשר רק את קובצי האפליקציה, קובצי מפות ושירותי חיפוש מוגבלים. `.git`, מסמכי העבודה, בדיקות, scratch ורשימות תיקיות אינם נגישים דרך המנהרה. פתרון קישורים מאפשר רק HTTPS ודומיינים מוכרים של Google Maps בכל הפניה, עם הגבלת זמן וגודל בקשה. שירות Photon הציבורי משמש לחיפוש מתון בגרסת הבדיקה בהתאם למדיניותו; אין הבטחת זמינות, ויש הגבלת קצב מקומית. זה אינו מסלול להעברת מידע הטיול לענן.

בקשות חיפוש דורשות הרשאת רשת לתהליך השרת. שרת מקומי המופעל תחת sandbox חסום לרשת יוכל להגיש מפות, אבל החיפוש יחזיר הודעת אי־זמינות.

קובץ `wrangler.preview.jsonc` ומודול `worker/index.js` מוכנים לאירוח קבוע נפרד ב־Cloudflare. לפני שימוש בהם יש להכין תיקיית נכסי פריסה עם קובצי האפליקציה והמקטעים בלבד, ולוודא הרשאות חשבון. אין בפרויקט אישור לחשבון בתשלום. לא נוצר Worker קבוע או R2 bucket. שינוי הקוד ב־GitHub אינו פריסה של קובצי המפה: יש להגדיר בנפרד אירוח קבוע למקטעים ושרת הכנה למדינות נוספות.

## שמירת מידע

`trip-planner` שומר נתונים רגילים ו־`trip-planner-maps` שומר נקודות וחבילות. הגיבוי המקומי מייצא רק את הראשון. מחיקת נתוני האתר או המכשיר עלולה למחוק גם נקודות מפה, שאין להן שחזור מגיבוי לפי בקשת המשתמש.

שחזור מלא ושחזור טיול בודד מחליפים נתונים בעסקת IndexedDB אחת. לאחר שחזור מוצלח, תכנון המפה ששויך לנתונים שהוחלפו מנוקה. חבילות מפה נשמרות. מחיקת כל הנתונים בהגדרות מנקה גם את מידע המפה והחבילות.

## בדיקות

```powershell
python dev-server.py 8124
node tests/run-browser.cjs
python preview-server.py 8125
node tests/smoke-map.cjs
python tests/update-server.py
node tests/smoke-update.cjs
```

סקריפטי הדפדפן משתמשים ב־Playwright המוטמע בסביבת Codex וב־Chrome מותקן. נתיב Playwright ניתן להתאמה לסביבת מפתח אחרת. פרופיל דפדפן זמני נפרד שומר על נתוני המשתמש הקיימים.

בבדיקה מ־2026-10-04 עברו 316 בדיקות דפדפן. בדיקת מפת בנגקוק אימתה רחובות, שמות, סמנים והערה לאחר הורדה, ניתוק רשת וטעינה מחדש. בדיקת החלפת Service Worker אימתה שימור כמות, נקודה, מקטע חבילה ומטמון שאינו שייך לאפליקציה; התקנה עם נכס חסר השאירה את המעטפת הקודמת זמינה אופליין. שחזור עם מזהה לא תקין או ערך שאינו ניתן לשמירה נבדק ואינו מוחק את הנתונים הקיימים.

הרחבת הלוויין והקטלוג העולמי נבדקה גם עם חבילת רחובות אמיתית וחבילת לוויין אמיתית של מלטה: הכנה, הצגת גודל לפני הורדה, הורדה דרך הממשק וטעינה מחדש אופליין. בנגקוק נבדקה בלוויין ובתצוגה משולבת, במסך מלא, בלי בקשות אריחים חיצוניות, ועם מחיקת הלוויין בלבד תוך שימור רחובות ונקודות. בדיקת API דחתה מזהים לא תקינים ובקשות גדולות ואימתה SHA-256 של חבילה שהוכנה. בדיקת Worker אימתה מקור הכנה חסר, הגבלת גוף בקשה וניתוב מקטעים לשרת המוגדר. כל שמונה חבילות הלוויין הראשונות הוכנו ואומתו; מדינות נוספות מוכנות לפי בקשה ולא כולן אוחסנו מראש.

אייפון אמיתי ואנדרואיד אמיתי עדיין דורשים בדיקת משתמש. בדיקת Chrome ברוחב טלפון אינה ראיה לתמיכה מלאה באחסון Safari, להורדת מדינה במכשיר בעל מעט מקום או להתנהגות מערכת ההפעלה כשהמסך נסגר. אפליקציה המותקנת למסך הבית יכולה לקבל אחסון מתמיד לפי החלטת הדפדפן, אבל אין הבטחה מוחלטת לשימור הנתונים: https://webkit.org/blog/14403/updates-to-storage-policy/ .
